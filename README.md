# ShepherdAI — الراعي الذكي (Kotlin + Compose)
تطبيق أندرويد محلي لتسجيل الأغنام والماعز بالصور والتعرف على الأفراد عند توفر نموذج ReID.

## الحالة
| الوظيفة | الحالة |
|---|---|
| تسجيل حيوان وصور مرجعية (CameraX) | منفّذ، لم يُختبر على جهاز |
| قاعدة بيانات Room (حيوانات، صور، بصمات، مشاهدات) | منفّذ، لم يُختبر على جهاز |
| تعرّف على الفرد عبر LiteRT + جيب التمام + رفض الغامض | منفّذ برمجياً، **ينتظر نموذجاً مدرباً** |
| فحص القطيع الحي: كشف (LiteRT) + تتبع IoU + عدّ + تقرير الناقص/الزائد | منفّذ برمجياً، **ينتظر كاشفاً مثبتاً**، لم يُختبر على جهاز |
| المصنّف، المراقبة عبر عدة جولات، التقارير الدورية، المساعد العربي، النسخ الاحتياطي | غير منفّذ |

## البناء
انسخ `gradlew` و`gradle/wrapper` من قالب Qeu، ثم `./gradlew assembleDebug`. أو ارفع المستودع إلى GitHub وسيبني `android-build.yml` ملف `ShepherdAI-debug.apk`.
